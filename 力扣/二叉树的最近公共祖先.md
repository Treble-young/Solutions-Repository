# 二叉树的最近公共祖先
[题目链接](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

## 解题思路
这是一道考察递归思维的经典题，理清分类讨论的依据是破题的关键

如果递归左子树的返回值为空，则说明`p,q`都在右子树，最近公共祖先也在右子树

如果递归右子树的返回值为空，则说明`p,q`都在左子树，最近公共祖先也在左子树

如果递归左右子树的返回值都不为空，则说明`p,q`一个在左子树，一个在右子树，当前节点即为最近公共祖先

边界情况：如果该节点为空，则返回`nullptr`

如果**该节点为p或q，则返回自身**，因为`q/p`一定是它的子节点，当前节点即为最近公共祖先

这两种情况可以放在一起讨论，都是返回自身

## 代码

```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if(!root||root==p||root==q)return root;
        TreeNode* l = lowestCommonAncestor(root->left,p,q);
        TreeNode* r = lowestCommonAncestor(root->right,p,q);
        if(l&&r)return root;
        else if(l)return l;
        return r;
    }
}
```
