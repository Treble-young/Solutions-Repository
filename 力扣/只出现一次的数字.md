# 只出现一次的数字
[题目链接](https://leetcode.cn/problems/single-number/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现**线性时间复杂度**的算法来解决此问题，且该算法**只使用常量额外空间**。

## 解题思路
依旧是一点思路都没有，`O(1)`的空间复杂度还是太折磨人了

但这毕竟是一道技巧题，**一回生二回熟，吃一堑长一智**

我们要把握住这题最关键的信息：其余每个元素均出现两次

如果我们能想出一种方法，使得出现两次的数字可以自行相消，这样最后剩下的就是只出现一次的数字

而位运算中的**异或**恰好具有这种性质，需要注意的是，别忘了异或的符号`^`

## 代码

```c++
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int temp = 0;
        for(int x:nums){
            temp = temp ^ x;
        }
        return temp;
    }
};
```
