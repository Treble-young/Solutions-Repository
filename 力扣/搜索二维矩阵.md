# 搜索二维矩阵
[题目链接](https://leetcode.cn/problems/search-a-2d-matrix-ii/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
编写一个高效的算法来搜索 m x n 矩阵 matrix 中的一个目标值 target 。该矩阵具有以下特性：

每行的元素从左到右升序排列。

每列的元素从上到下升序排列。

![示例](图片/searchgrid2.jpg)

输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5

输出：true
## 解题思路
由于矩阵的每一行都是升序的，所以可以使用`binary_search`进行**二分查找**。

但是，由于该矩阵每一列都是升序的特性，本题还有一种更好的解法：**Z 字形查找**

我们可以从矩阵 `matrix` 的右上角 `(0,n−1)` 进行搜索，记行数为i，列数为j

如果`matrix[i][j]` > `target`,则说明这一列的数都大于`target`，令`j--`

如果`matrix[i][j]` < `target`,则说明这一行的数都小于`target`，令`i++`

如果`matrix[i][j]` = `target`,则返回`true`

如果超出了矩阵的边界，则说明不存在`target`，返回`false`

## 代码

```c++
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size(), n = matrix[0].size();
        int x = 0, y = n - 1;
        while (x < m && y >= 0) {
            if (matrix[x][y] == target) {
                return true;
            }
            if (matrix[x][y] > target) {
                --y;
            }
            else {
                ++x;
            }
        }
        return false;
    }
};

```
