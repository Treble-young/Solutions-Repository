# 最长回文子串
[题目链接](https://leetcode.cn/problems/longest-palindromic-substring/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
给定一个字符串 s，找到 s 中最长的回文子串，如果存在多个长度相同的最长回文子串，则输出在原字符串中最先出现的那个。

## 解题思路
说实话，刚看到这道题是一点思路也没有，只是觉得**双循环**太蠢了，但其实只要在这个思路上稍微优化一下就行：

涛哥的思路：

外循环i，内循环j从i开始遍历，每次检验`s[i]`到`s[j]`之间的子串是否是回文串

具体如何检验呢？先计算子串的长，如果长度大于当前的`ans`才有可能成为答案，如果小于等于`ans`，就算是回文串也没用，相当于进行了**剪枝处理**

下一步计算出子串的半长`m`，利用`substr`函数取得子串的前一半和后一半（注意`substr`函数的用法：（下标，长度）），然后`reverse`后一半，再与前一半进行比较，以此来判断是否回文

但是，正如一开始提到的，这个方法虽然能过，但并不是最优解，下面将要介绍**中心扩展算法**

回文串**只有两种情况**：奇数长度和偶数长度，我们可以在这两种情况上扩展得到所有可能

我们编写一个函数：输入两个初始下标，返回以此为基础的最大回文长度的左下标和右下标

判断的条件非常简单：只要`s[i]==s[j]`就继续判断，否则退出

于是我们只需要遍历一次`s`，每次检测`(i,i)`与`(i,i+1)`即可，只要返回的长度大于`ans`就更新答案

其实还有一个复杂度为 `O(n)` 的 `Manacher` 算法。然而本算法十分复杂，暂时不进行研究

## 代码
**双循环**
这是当时在matrix上写的，与力扣上直接实现函数有所不同
```c++
#include<iostream>
#include<string>
#include<algorithm>
using namespace std;
int main(){
    string s,temp;cin>>s;
    int i = 0,j,l = s.size(),ans=0,index=0;
    for(;i<l;i++){
        for(j=i;j<l;j++){
            int m = (j - i + 1)>>1;
            if(j-i+1>ans){
                string a = s.substr(i,m), b = s.substr(j-m+1,m);
                reverse(b.begin(),b.end());
                if(a==b){
                    ans = j-i+1;
                    index = i;
                }
            }
        }
    }
    cout<<s.substr(index,ans);
}
```

**中心扩展算法**

```c++
class Solution {
public:
    pair<int, int> expandAroundCenter(const string& s, int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            --left;
            ++right;
        }
        return {left + 1, right - 1};
    }

    string longestPalindrome(string s) {
        int start = 0, end = 0;
        for (int i = 0; i < s.size(); ++i) {
            auto [left1, right1] = expandAroundCenter(s, i, i);
            auto [left2, right2] = expandAroundCenter(s, i, i + 1);
            if (right1 - left1 > end - start) {
                start = left1;
                end = right1;
            }
            if (right2 - left2 > end - start) {
                start = left2;
                end = right2;
            }
        }
        return s.substr(start, end - start + 1);
    }
};
```
