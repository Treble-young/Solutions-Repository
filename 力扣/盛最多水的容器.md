# 盛最多水的容器
[题目链接](https://leetcode.cn/problems/container-with-most-water/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：你不能倾斜容器。**(出题人可爱捏)**

## 解题思路
虽然标签同样为双指针，但是和上一道题（移动零）还是有很大的区别，我绞尽脑汁不如龙哥灵机一动：

一个指针在左端，另一个指针在右端，每次循环先更新答案，然后高度更低的指针向对方移动，直到两个指针相遇

为什么这个方法可行？明明它没有遍历所有情况？

原理很简单，指针向内移动，意味着区域宽度变窄，如果移动较高的指针，则区域面积必然缩小，就不用考虑这种情况了，说白了就是**剪枝处理**

## 代码
```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int ans=0,p=0,q=height.size()-1;
        while(q>p){
            ans=max(ans,(q-p)*min(height[p],height[q]))
            if(height[p]<height[q]){
                p++;
            }
            else{
                q--;
            }
        }
        return ans;
    }
};
```
