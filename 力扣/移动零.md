# 移动零
[题目链接](https://leetcode.cn/problems/move-zeroes/description/?envType=study-plan-v2&envId=top-100-liked)

## 题目描述
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意 ，**必须在不复制数组的情况下原地对数组进行操作**。

## 解题思路
最初的思路如下：

**开辟一块新的内存空间**，单指针遍历，如果读到0就跳过，否则写入新空间；遍历完之后补齐0就行

算法的复杂度自然是没问题，但是超出了题目给定的空间限制

龙哥的思路：

**双指针 一读一写**

1、如果读指针读到0，写指针不动，读指针向前移动

2、如果非0，写指针写入读指针的数据，两个指针都向前移动

3、如果读指针走到尽头，则写指针将剩余的0补齐

## 代码
```c++
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        for(int i=0,j=0;i<nums.size();){
            if(j==nums.size()){
                nums[i]=0;
                i++;
            }
            else if(nums[j]){
                if(i==j){
                    i++;
                    j++;
                }
                else{
                    nums[i]=nums[j];
                    i++;
                    j++;
                }
            }
            else{
                j++;
            }
        }
    }
};
```
